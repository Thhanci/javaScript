- ### 1. `flex-direction: column;`（改变排列方向）

  - **意思**：设置主轴的方向为**垂直方向**（从上到下）。
  - **默认情况**：Flex 布局默认是水平方向（`row`，从左到右）。
  - **加上这句后**：子元素不再横着排，而是**竖着排**（像列表一样）。

  ------

  ### 2. `justify-content: center;`（主轴居中）

  - **意思**：让子元素在**主轴**（这里就是垂直方向）上**居中**。
  - **效果**：因为主轴变成了垂直方向，所以子元素会在**垂直方向（上下）** 上居中。
  - **如果没有这句**：子元素可能会紧贴着容器顶部。

  ------

  ### 3. `align-items: center;`（交叉轴居中）

  - **意思**：让子元素在**交叉轴**（这里就是水平方向）上**居中**。
  - **效果**：因为交叉轴是水平方向，所以子元素会在**水平方向（左右）** 上居中。
  - **如果没有这句**：子元素可能会紧贴着容器左侧。
